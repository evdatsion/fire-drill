# Tiers and sampling

## Tier rules

The drill ranks files by how hard they would be to replace, decided by written rules, not by judgment calls in the moment:

| Tier | What qualifies | How it is identified |
|---|---|---|
| Tier 1: irreplaceable | Photos of people and pets, family events | Photo search matched into person and pet albums (figure and pet parameters) |
| Tier 2: hard to replace | Documents: PDF, office files, scans | Document type search inside the scoped folders |
| Tier 3: everything else | Screenshots, downloads, media, misc | Screenshot search (screen category) and the remainder |

A folder with no tier 1 files carries no single-copy risk at all, whatever it contains. This is what keeps a screenshots-only folder from being graded as "irreplaceable at risk".

Folders are also labelled with their owner, for example "Mom's iPhone", from the scope the user gave. The Report Card is one page per folder.

## Sample sizes

Per source folder, per drill:

- Tier 1: up to 30 files.
- Tier 2: up to 20 files.
- Tier 3: up to 10 files.

If a tier holds fewer files than its sample size, sample all of them. If a folder holds fewer than 5 files in total, open-test every file in it.

## Selection rule

Weight the sample toward older files, because old files fail first:

1. Sort the tier by modification time, oldest first.
2. Take at least one quarter of the sample from the oldest quarter of the tier.
3. Spread the rest evenly across the remaining age range so recent files are checked too.

Never sample by name or by folder order; sample across the whole tier so a moved subfolder cannot hide from the drill.

## Honest confidence

The report always states the sample fraction, for example: "opened 30 of 412 people photos; 29 opened, 1 failed, 0 could not be checked."

- Never write "your photos are fine" or any whole-library claim. The drill opens a sample; it says so every time.
- Files that could not be attempted are reported separately, not counted as passes.
- A folder where the whole sample could not be attempted gets "could not check" for the open test and the folder is not graded.
- If a tier is empty, the report says "none found" for that tier instead of inventing a number.
